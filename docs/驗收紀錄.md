# 驗收紀錄

## 0.5.1（2026-11-20，修正版）

修正：從 PowerShell 7 打開的貼貼（例如用 PowerShell 7 貼安裝指令後，還沒重開機），按「立即更新」會默默失敗。現在呼叫安裝程式時不再帶著 PowerShell 7 的模組路徑；安裝輸出記在 `update.log`；安裝沒成功時會跳出「沒辦法自動更新」並附上手動安裝指令（Mac、Windows 都是）。Mac 加上 pipefail，下載失敗才會被當成失敗。

| 項目 | 方式 | 結果 |
|---|---|---|
| Mac 自我檢查（含更新結束碼、update.log、下載失敗算失敗） | `--selftest`，私有剪貼簿 | 48 項通過，0 失敗 |
| Windows 自我檢查（從 PowerShell 7 環境跑，含解壓縮與模組路徑） | GitHub Actions windows-latest | 通過 |
| Windows 從 PowerShell 7 打開後按「立即更新」實際安裝 | CI，指向假的 v9.9.9，安裝這次組好的 zip | 通過，舊版關閉、新版裝好並自動打開（0.5.0 在同樣情況會失敗） |
| Windows 更新失敗的提示 | CI，安裝檔指向不存在的檔案 | 通過，跳出「Couldn't update automatically」與手動安裝指令，貼貼沒有當掉 |
| Windows 搜尋畫面各語言截圖 | 改成直接放入搜尋字後重拍 | 通過，七種語言都只剩符合的那一筆 |

### 未驗
- Mac 更新失敗的提示視窗沒有實際跳出來看（實際跑安裝指令會關掉所有叫 Tietie 的程式，包含奎嵐正在用的那一個）；判斷失敗的部分由自我檢查驗過。

### 已知風險
- 用 PowerShell 7 貼安裝指令的人，貼貼會繼承 PowerShell 7 的模組路徑，在重開機之前按「立即更新」會默默失敗（重開機後由開機自動啟動打開就正常）。0.5.1 已修正。

### 未驗
- Windows「搜尋」畫面的各語言截圖：截圖流程用模擬鍵盤打字，搜尋字沒有打進去，拍到的跟清單一樣。搜尋功能本身在 Windows 實際操作測試中通過（0.5.1 已補拍）。
- 日、韓、葡、西翻譯沒有母語者看過。
